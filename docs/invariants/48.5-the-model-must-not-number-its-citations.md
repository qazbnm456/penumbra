# Invariant 48.5: The model must not number its own citations

**The model must not number its own citations.**

The interface numbers citations itself, in reading order, and draws each as a mark on the span the model named. A `[1]` written into the sentence is a second, competing scheme, and the two disagree on screen.

The rule is enforced in the prompt only. Invariant 62 strips `[[SRC:...]]` at the display layer because that marker is unambiguous, whereas a bare `[1]` is not: `arr[1]` is ordinary prose in this project's subject matter, and stripping it would corrupt a quote or a code snippet to tidy a number. As with invariants 4 and 11, this is prompt compliance that the offline suite cannot demonstrate.
